Nesta atualização, configuramos:
As sub-redes para comportar o número de máquinas pedido;
Endereços IP de cada computador e servidor manualmente;
Servidor DHCP na LAN3;
ACL para bloquear tráfego vindo da LAN1 para LAN3.

LAN1:
O switch0 precisa de uma capacidade para 110 máquinas, logo, precisamos de 2^7 = 128 endereços.
Isso nos dá uma sub-rede igual a 255.255.255.128/25
Switch0: 120.20.30.1/25

O switch1 precisa de uma capacidade 31 máquinas, 2^5 = 32, mas 2 endereços são tomados por padrão, logo, precisamos de 2^6 = 64 endereços.
Isso nos dá uma sub-rede igual a 255.255.255.192/26
O primeiro endereço usável começa no 129, pois no switch0 reservamos 128. Logo, para o switch1, reservaremos até 128 + 64 = 192 endereços.
Switch1: 120.20.30.129/26

LAN2:
Aqui, precisamos dividir a sub-rede em 4 tamanhos de endereços iguais. 
Os primeiros 16 bits são destinados à rede. Logo: 16 / 4 = 4 = 2^2. Vamos pegar 2 bits emprestados.
16 + 2 = 18, isso dá uma sub-rede igual a:
11111111.1111111.11000000.00000000 = 255.255.192.0
Portanto, teremos:
Switch4: 192.168.0.1/18
Como o terceiro octeto é 192, fazemos: 256 - 192 = 64 tamanhos de endereços.
Switch5: 192.168.64.1/18

LAN3:
Não precisamos calcular a sub-rede.
Switch6: 10.0.0.1/18

DHCP:
Configurar endereço IP do servidor manualmente na LAN3
Ir em Services -> DHCP -> ON e configurar o DHCP baseado no endereço IP da LAN3.

Comandos para configurar ACL:
en
conf t
interface g0/0
ip access-list SACL
ip access-list extended SACL
deny ip 120.20.30.0 0.0.0.255 10.0.0.0 0.0.63.255
permit ip any any
exit
interface g0/0
Router(config-if)# ip access-group SACL in
